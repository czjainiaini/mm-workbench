# 魅魔工作台（MM Workbench）

一个面向 sexyai.ai 聊天页的**可视化美化工具**：不用写代码，就能给聊天页面换配色、换图片、加组件、点哪改哪，最后一键导出为平台可导入的美化包或直接发布到你的角色卡。

> 本项目是独立的个人工具，与 sexyai.ai 平台无隶属关系；请遵守目标平台的服务条款，仅美化你自己有权修改的内容。

## ✨ 能做什么

| 功能 | 说明 |
|---|---|
| 🎨 一键换配色 | 8 套预设色板 + 自定义主色，97 个区域全覆盖（含弹窗） |
| ◐ 工作台主题 | 紫夜、深海、森屿、玫瑰、暖茶、雾蓝 6 套界面主题，和沙盒页面配色互不影响 |
| 🧩 组件画布 | 勾选卡片启用、拖拽排序、可视化调参（颜色/圆角/字号） |
| 🖼 素材库 | 选图片位 → 贴图床直链，替换头像/底图/图标，可还原 |
| 🧱 插槽 & 画布拖放 | 悬浮按钮/横幅/侧边栏等 6 个插槽；模块可拖到页面任意位置 |
| ↩ 安全试错 | 页面配色、组件、AI 样式和快捷修改统一支持撤销/重做与前后对比，最多保留 30 步 |
| ✏️ 点选编辑 | 点沙盒任意元素改属性，支持位置覆盖拖动和独立撤销 |
| 🗂 项目工作室 | 4 套创作模板、最多 30 份项目快照、恢复前自动备份、变更历史与发布前 Test Mode |
| 🤖 AI 助手 | 三档执行模式；可设置上下文预算与输出上限，旧对话自动压缩为持久摘要，会话跨刷新保留 |
| 📤 导出/发布 | 汇总全部改动为平台兼容 JSON；导出自动检查包结构，发布还会强制验证真站聊天页与实时桥 |

## 🖥 环境要求

- **Node.js 16+**（仅用到内置模块，无需 npm install）
- Windows 用户可直接用启动脚本；macOS/Linux 用命令行启动
- 现代浏览器（Chrome / Edge 推荐）

## 🚀 启动方法

**Windows（最简单）**：双击 `启动工作台.bat`，自动开服务并打开浏览器。

**命令行（全平台）**：

```bash
node server.js
# 或指定端口
PORT=9000 node server.js   # macOS/Linux
set PORT=9000 && node server.js   # Windows
```

**访问地址**：<http://localhost:8793/wb/workbench.html>

**离线自检**（维护者或更新后想确认功能时）：

```bash
node scripts/smoke-test.js
```

自检只启动本机临时服务，不请求目标站点或模型 API。

## 🔄 如何更新到新版本

**当初用 git clone 下载的**：进入项目文件夹执行一条命令即可：

```bash
git pull
```

**当初下载 ZIP 解压的**：重新到仓库页面下载最新 ZIP，解压覆盖旧文件夹即可。
不用担心丢东西：你的配色/组件/素材/AI 档案等配置都存在浏览器本地，不在项目文件里；覆盖后双击启动脚本照常用。

## 🛠 Git 使用小抄（想参与开发/自己管理版本看这里）

**第一次获取代码**：

```bash
git clone https://github.com/czjainiaini/mm-workbench.git
cd mm-workbench
```

**日常更新**：`git pull`（拉取远程最新提交）。

**改了代码想提交**：

```bash
git add -A
git commit -m "一句话说明改了什么"
git push        # 需要仓库写权限；fork 用户向自己仓库 push 后提 PR
```

**常用命令速查**：

| 想做什么 | 命令 |
|---|---|
| 看当前改了什么 | `git status` / `git diff` |
| 看提交历史 | `git log --oneline` |
| 撤销未提交的修改 | `git checkout -- 文件名` |
| 回到某个历史版本看看 | `git checkout 提交号`（看完 `git checkout main` 回来） |
| pull 时提示冲突 | 先 `git stash` 暂存自己的改动，pull 后 `git stash pop` |

**Windows 小提示**：提交信息含中文时若乱码，在终端先执行 `chcp 65001` 再提交；或把提交信息存成 UTF-8 文本文件后用 `git commit -F 文件名`。

**注意事项**：仓库 .gitignore 已排除截图、第三方参考美化包等本地私有内容，`git status` 里看不到它们是正常的，不要强行添加。

## 📖 新手三步上手

1. 首次打开跟着 1 分钟互动引导，点 **打开真站聊天页**；这里使用真实页面结构，编辑后能立即看见效果
2. 若出现登录或人机验证，点顶栏 **新页打开** 完成登录，再回工作台刷新；预览改动不会自动发布
3. 在引导里选择一套配色并练习 **撤销**；之后到 **项目** 页保存快照、运行 Test Mode，再导出或发布

本地复刻只保留为功能不完整的离线演示，适合断网排查基础样式，不推荐用于真实编辑或最终验收。顶栏 **工作台主题** 可切换 6 种界面颜色，且不会改变正在制作的页面配色。

## 🗂 长期创作闭环

1. **模板库**：沉浸紫夜、深海阅读、暖茶长篇、森屿清新；套用前自动保存恢复点
2. **实时精修**：在真站聊天页用配色、组件、素材、插槽或点选编辑即时查看结果
3. **项目快照**：保存阶段版本，恢复时再自动备份当前状态；可导入/导出 JSON 换机备份
4. **变更历史**：回顾最近操作；需要真正回退时使用快照或全局撤销/重做
5. **Test Mode**：检查包结构、重复/缺失规则、能力范围、真站连接、实时桥、聊天结构与图片状态，并显示相对最近快照的差异

项目快照只包含项目文件、组件、素材、点选、插槽与画布数据，**不包含 API Key、模型档案、AI 会话、角色 ID 或登录态**。

## 🧠 AI 上下文与持久记忆

在 AI 面板右上角打开大模型设置，可以配置：

- 上下文预算（2K–128K tokens）与输出上限（256–8192 tokens）
- 自动压缩后保留的最近轮次
- 是否在接近预算时自动把旧对话压缩为持久摘要

AI 的可见对话、最近模型轮次和摘要按会话保存在浏览器本地。刷新或重启工作台后会恢复；也可以点击“压缩当前会话”手动整理。模型密钥与聊天记忆不会进入项目快照。

## ❓ 常见问题

- **沙盒空白？** 直接点沙盒中央的「打开真站聊天页（推荐）」，或从顶部「沙盒」下拉选择；真站模式首次需要登录（见下条）
- **沙盒里登录不了/人机验证失败？** 登录页的人机验证（Cloudflare Turnstile）在沙盒嵌套窗口里无法通过，属环境问题非账号问题。解决：点工具条「新页打开」（或浏览器直接访问 <http://localhost:8793/>）在独立页面登录，再回工作台刷新沙盒——两者同源，登录态自动共享（登录态按端口隔离，换端口需重登）
- **样式没生效？** 等徽章「已加载」再操作，或点工具条 ⟳ 刷新沙盒
- **换色后不喜欢？** 点设备栏或简洁模式快捷栏的「撤销」；误撤销可点「重做」，「前后对比」只临时隐藏效果
- **AI 只认固定指令？** 未配置 API Key 时为规则引擎模式；点右上 ⚙ 配置端点与 Key（支持多档案一键切换）后即可理解任意说法
- **数据存在哪？** 项目、快照与 AI 会话存在浏览器 localStorage；换浏览器前可从“项目 → 项目快照”导出备份，清缓存会重置本地数据

## ⚠️ 注意事项

- 所有改动只在本地沙盒预览，**不点「发布到角色卡」就不会影响线上**
- 发布是把美化写入你的角色卡（所有使用该卡的用户可见），请先在沙盒确认满意
- 发布/清除等高风险操作，任何执行模式下都会要求手动确认
- `mock/` 目录是功能不完整的本地页面演示，仅供离线排查和学习参考，不代表真站最终效果；其中图标全部为项目自绘（scripts/gen-mock-icons.js 可重新生成）

```
sw.js               Service Worker（代理辅助）
启动工作台.bat       Windows 一键启动
src/                加载器 / 发布器 / 项目工作室 / 全位置样式注册表
mock/               本地复刻页与图标资源
scripts/            注册表生成器
skills/             AI 能力清单
```
