# 魅魔工作台 · 技能库（能力清单）

> 借鉴 Pi Agent 的"渐进式披露"思路：AI 不需要把所有能力细节塞进系统提示词，
> 你（用户）看这份清单即可知道能让我做什么；AI 的系统提示只保留动作协议，
> 沙盒类名参考按首轮快照随需注入。

## 一、对 AI 说就行（自然语言指令）

| 你可以说 | 我会做什么 |
|---|---|
| 换成粉色配色 / 深蓝主题 / 暗黑配色 | 全区域主题：背景、顶栏、双气泡、状态栏、快捷栏、输入区一次全覆盖 |
| 把 AI 气泡改成 #5b21b6 | 局部样式修改（气泡/顶栏/状态栏等任意区域） |
| 字号调到 18px / 行距 1.8 | 正文排版调整 |
| 美化状态栏 | 状态栏高亮样式 |
| 清除注入 / 还原 | 清掉工作台注入的实时样式 |
| 装载美化包 | 把 package.json（功能栏导出格式）注入沙盒预览 |
| 发布 | 把 package.json 一键写入角色卡（正则 upsert + 卡片字段回写） |
| 体检 | 沙盒健康检查（桥/容器/美化包状态） |
| 夜间 / 日间 | 切换已装载美化包的日夜主题（需先装载含切换功能的包） |

## 二、支持的美化包格式（tavern-mmd 双格式）

1. **MMD 导入 JSON**：`pageDepth / statusbar / beginning / regex_scripts[{id:-1,scriptName,findRegex,replaceString}]`
2. **SillyTavern 正则数组**：含 `placement/markdownOnly/disabled` 等全字段的数组，或卡内嵌 `data.extensions.regex_scripts`
   - `disabled:true` 的规则自动跳过；130 条上限自动校验

## 三、手动操作入口

| 入口 | 位置 | 用途 |
|---|---|---|
| 编辑页签 | 顶部页签 | 手写 CSS/JS，实时注入沙盒（自动验证选择器命中） |
| 🚀 发布到角色卡 | 编辑页签应用栏 | 发布 package.json |
| ＋ 新聊天 / ☰ 历史会话 | AI 面板头部 | 多会话管理（自动标题、切换、删除有确认） |
| 🗑 清空当前对话 | AI 面板头部 | 清空后 30 秒内可"↩ 撤销"恢复 |
| ⚙ 大模型设置 | AI 面板头部 | Base URL / Key / 模型 / 拉取模型列表 / 纯文本模型开关 |

## 四、AI 执行约定（你会看到什么）

1. 你发指令 → AI 先给**执行计划卡片**（确认才动手）
2. 点执行 → **过程卡片逐步刷新**：⏳执行中 → ✅成功（附验证结果）/ ❌失败（附原因）
3. 有失败项 → 自动把结果回喂模型**修正**（最多 2 轮），仍失败会告诉你原因和下一步
4. 全部记录进会话（刷新不丢）+ 修改历史（右侧"修改记录"）

## 五、暂无 Key 时的降级模式

未配置大模型 API Key 时自动使用内置规则引擎（仅识别上表固定指令），
界面会有黄色"⚠ 降级模式"提示。配置 Key 后可理解任意开放式指令。
